CHIP SCHEME CHEAT SHEET   (R7RS-small subset, written in Forth, emulated STM32F446)
==================================================================================
Start:  stm32-lisp          (boots QEMU, loads the Scheme, gives the  >  prompt)
Layers: assembly -> SBCL breadboard -> our own Forth kernel -> this Scheme.
        The Scheme is Forth source loaded through the chip's Forth console.
Edit:   Backspace and Delete both erase.  An expression may span lines.

SWITCHING
  (forth)          leave Scheme, back to the Forth  ok.  prompt
  lisp             (at the Forth prompt) re-enter Scheme
  Ctrl-C           quit QEMU

DATA
  42  -7  1/3  2.5     exact integers (31 bits; overflow is an error), rationals,
                       single-precision floats
  #t #f                booleans; only #f is false ('() is true)
  #\a  "a b\n"         characters (bytes), strings
  #(1 2 3)  #u8(1 2)   vectors, bytevectors
  'a  '(1 2 . 3)       symbols, lists, dotted pairs

SPECIAL FORMS AND MACROS
  (define x 10)  (define (f a . rest) ...)   (set! x 11)
  (lambda (x) ...)  (if c a b)  (cond ...)  (case ...)  (and ...)  (or ...)
  (let ...)  (let* ...)  (letrec ...)  (do ...)  (when ...)  (unless ...)
  (define-syntax m (syntax-rules () ((_ x) ...)))   not hygienic
  `(a ,b ,@c)   (delay x)  (force p)   (guard (e (#t ...)) body)
  (parameterize ((p v)) ...)   (define-record-type ...)   (case-lambda ...)
  (let-values (((q r) (floor/ 7 2))) ...)   (call/cc ...) escape-only

EXAMPLES TO TYPE   (each one is checked on the emulated chip)
  (define (fact n) (if (< n 2) 1 (* n (fact (- n 1)))))
  (fact 10)                                   => 3628800
  (map + '(1 2 3) '(10 20 30))                => (11 22 33)
  (/ 6 4)                                     => 3/2
  (+ 1/2 0.25)                                => 0.75
  (sqrt 16)                                   => 4
  (round 7/2)                                 => 4
  (string-append "ab" "cd")                   => "abcd"
  (vector-ref #(1 2 3) 2)                     => 3
  (char-upcase #\a)                           => #\A
  (let ((x 5)) `(x ,x ,@(list 1 2)))          => (x 5 1 2)
  (call/cc (lambda (k) (+ 1 (k 42))))         => 42
  (guard (e ((string? e) e)) (raise "oops"))  => "oops"
  (guard (e (#t (error-object-message e))) (car 5))   => "not a pair"
  (let-values (((q r) (floor/ 17 5))) (list q r))      => (3 2)
  (force (delay (* 6 7)))                     => 42
  (let loop ((i 0)) (if (< i 10000) (loop (+ i 1)) i))   => 10000
  (+ 1073741823 1)                            => overflow

LIMITS
  60 KiB cons heap, 12 KiB string/vector heap, 10 KiB symbol names
  tail calls run in constant stack; deep non-tail recursion: too deep
  continuations are escape-only; syntax-rules is not hygienic
  Errors print a message and return to  >  unless a handler catches them
